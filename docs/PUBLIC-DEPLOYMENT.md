# 部署与他人使用

本项目包含Node后端，GitHub公开仓库用于保存和分发源码。GitHub Pages不能直接运行模型问答、鉴权和学习统计接口。

## 在自己电脑运行

1. 安装Node.js 22或更新版本，以及Git。
2. 克隆仓库并进入目录。
3. 将`.env.example`复制为`.env`。
4. 填写自己的模型接口地址、模型名、API密钥，以及两个不同的访问口令。密钥和口令不要提交到仓库。
5. 运行`npm start`，浏览器打开`http://127.0.0.1:3360`。

核心服务没有第三方运行依赖，无需先安装项目依赖。`npm test`运行行为测试；浏览器测试依赖本机Playwright及Edge，仅作为可选开发验收。

## 部署到Linux服务器

1. 在服务器安装Node.js 22+、Nginx和PM2，将仓库克隆到独立目录。
2. 在服务器创建`.env`并填入自己的配置，设置`HOST=127.0.0.1`、`PORT=3360`；通过Nginx反代时设置`TRUST_PROXY=1`。
3. 运行`pm2 start deploy/ecosystem.config.cjs`，再运行`pm2 save`；按PM2提示配置开机自启。
4. 参考`deploy/nginx.conf.example`替换自己的域名和目录，配置HTTPS证书。对外开放80/443，后端3360只监听回环地址。
5. 打开自己的HTTPS域名，输入在服务器配置的访问口令，检查知识库、问答与原文来源。

升级时备份服务器配置和学习数据；保留已有`.env`，更新源码与知识文档后重启PM2。不要直接用本机`.env`覆盖服务器配置。

## 如何给其他人使用

- 使用现有网站：提供已部署的网站地址与普通访问口令。教师端口令单独管理。
- 自行部署：分享仓库，使用者自行配置模型服务与口令。
- 本机地址`127.0.0.1`只能在运行服务的那台电脑访问，不能作为分享链接。

## 内容范围

知识库包含28篇正文与9份历史证据档案。来源链接、全文读取与专业审核是不同状态；具体状态以每篇资料标记为准。历史证据档案只供查阅，不进入当前问答检索。本仓库不附原始文献PDF、模型密钥、现用口令、个人学习记录或运行日志。
