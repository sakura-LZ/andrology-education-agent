# 模块九：辅助生殖基础与男科衔接

> 整理日期：2026-11-22。状态：知识框架初稿，待专业复核。最新指南和统计尚未完成联网核验；旧版未核定成功率表不再作为默认正文，改动前原稿已备份。

## 一、先把技术名称分清

医学辅助生殖的范围和统计口径可能不同。IUI 可与 IVF/ICSI 一起讨论临床路径，但在部分国际统计定义中，IUI 不属于需体外处理卵母细胞/胚胎的 ART 范畴。引用统计时必须说明采用的定义。

| 技术 | 核心过程 | 不能混同的概念 |
|---|---|---|
| IUI 宫腔内人工授精 | 处理后的精子置入宫腔，受精仍在体内 | 与 IVF 体外受精不同 |
| IVF 体外受精 | 卵母细胞与精子在体外结合，再进入胚胎培养与后续流程 | 受精成功不等于活产 |
| ICSI 卵胞浆内单精子注射 | 显微操作将精子注入卵母细胞 | 不会自动解决所有精子遗传与功能问题 |
| PGT 胚胎植入前遗传学检测 | 针对特定遗传问题或相应指征评估胚胎 | PGT-M、PGT-SR、PGT-A 的用途不同，不能统一写成提高成功率 |

“第几代试管”是常见称呼，不能用代际编号推断技术普遍更先进或适合所有人。

### 1.1 IUI：把精子送入宫腔，受精仍在体内

IUI 的英文是 intrauterine insemination。宫腔是子宫内部的空间；通常精卵相遇和受精发生在输卵管，而不是把精液注入子宫后就在子宫里完成受精。IUI 改变的是精子进入女性生殖道的方式，并没有把受精过程搬到实验室。

基本过程包括：先评估双方条件与周期安排，确认这条路径是否适用；采集并核对精液样本，再由实验室处理，获得用于授精的精子悬液；在合适时机将处理后的样本送入宫腔，随后按计划随访是否妊娠。这里的精液处理涉及精子分离和去除不宜直接注入宫腔的精浆等成分，不是把原始精液直接注入，也不是完成遗传筛查。

理解每步的目的，有助于看清限制：安排时机是为了配合排卵，处理样本是为了准备适用的精子，宫腔内授精减少的是部分输送环节。后续仍依赖相应的排卵、输卵管及受精条件。因此，完成授精不等于已经受精，更不等于已经怀孕。

### 1.2 常规 IVF：在体外让精子与卵母细胞结合

IVF 的英文是 in vitro fertilization，即体外受精。卵母细胞是参与受精的女性生殖细胞，日常常称为卵子。常规 IVF 在实验室将准备好的精子与卵母细胞共同培养，由精子完成与卵母细胞结合、进入等受精过程。

基本过程是先完成双方评估与相应周期管理，再获取卵母细胞和精子；实验室处理配子后进行受精，检查受精表现，继续培养并评估胚胎，随后根据方案冻存或移植。胚胎移植是将胚胎送入子宫腔；着床则是胚胎随后与子宫内膜建立联系的过程，二者不能混为一个动作。

取到卵母细胞不代表每个都成熟，成熟也不代表都能正常受精；观察到受精，也不代表每个胚胎都能继续发育。讲解 IVF 时，应保留这些环节之间的区别，不能用“取卵后放回去”概括整个过程。

### 1.3 ICSI：改变受精环节，后续仍需培养与移植

ICSI 的英文是 intracytoplasmic sperm injection，即卵胞浆内单精子注射。卵胞浆是卵母细胞膜内的细胞质；这项技术利用显微操作，将选取的单个精子注入成熟卵母细胞的胞浆。它与常规 IVF 的关键区别在受精方式，而不是省略取卵、胚胎培养或移植。

基本过程包括：评估采用 ICSI 的理由，准备卵母细胞和精子，判断卵母细胞成熟情况并选择适用精子，完成显微注射，再观察是否正常受精，进入后续培养、保存和移植安排。外科取精获得的精子也可能在这条路径中使用，因此男科手术和胚胎实验室需要提前协调。

显微下看到的形态和活动情况，只是精子评价的一部分。把精子送入胞浆，不等于已经确认其遗传信息正常，也不保证卵母细胞激活和胚胎后续发育。不能把 ICSI 讲成“挑出一个最好的精子，所以后面一定成功”。

### 1.4 PGT：针对特定问题检测胚胎，不是另一种受精方式

PGT 的英文是 preimplantation genetic testing，即胚胎植入前遗传学检测。它是在 IVF/ICSI 获得胚胎后的相关路径中，对胚胎样本进行遗传学检测；不是把精子注入卵母细胞的另一种方法，也不是直接修复基因。

PGT-M 针对单基因疾病相关问题；PGT-SR 针对染色体结构重排相关问题；PGT-A 主要评估染色体数目异常。单基因疾病涉及特定基因的致病变异，结构重排涉及染色体片段的位置或结构改变，数目异常则涉及染色体数量改变。三类检测回答的问题不同，不能只写作同一种“胚胎筛查”。

大致过程是先确认检测指征并完成遗传咨询，明确要回答的遗传问题与检测方案；获得并培养胚胎后，在适用阶段取得细胞样本，进行检测并解释结果，再讨论后续保存与移植安排。取样和检测的对象、方法与限制需要记录清楚。

检测结果并不涵盖所有疾病和发育问题。样本对整个胚胎的代表性、检测范围和技术限制也会影响解释。是否适用，以及妊娠后是否需要进一步产前评估，应在遗传咨询中讨论，不能将 PGT 结果表述为健康子代保证。

## 二、男科评估怎样进入路径

从规范精液分析、病史、查体和必要的激素/遗传检查出发，明确可逆因素、梗阻性或非梗阻性无精子症以及生育力保存需求。同时结合女方年龄、卵巢储备、输卵管情况、既往治疗和双方目标讨论时间与路径。

不是所有人都需要同一套检查；DFI 等附加检查应按适用问题决定。既不能只因某个指标异常就跳过评估，也不能忽略女方时间因素而无限等待男方参数改善。

## 三、IUI、IVF 与 ICSI 的选择框架

IUI 的可行性需要结合处理后精子状况、排卵和输卵管等因素；IVF 与 ICSI 的选择涉及精子来源/数量/功能、既往受精情况和具体诊断。不能给所有人套一个统一浓度阈值或一条年龄界线。

外科取精与 ICSI 通常紧密配合，术前要协调实验室精子搜索、处理和冻存。遗传异常需考虑对子代的影响与咨询；ICSI 是受精技术，不能解释为消除了遗传风险。

## 四、一个治疗周期的基本环节

治疗前评估与知情同意 → 按个体方案完成卵巢刺激或相应周期管理 → 获取配子 → IVF/ICSI 受精 → 培养与评估 → 按指征进行遗传检测或冻存 → 按适当时机移植 → 随访妊娠结局。

这是一条概念链，不是所有周期都当期移植；冻存、检测、移植安排会改变流程。具体药物、剂量与操作参数属于生殖医学专业方案。

### 4.1 这些环节分别在解决什么问题

| 环节 | 主要目的 | 本环节的结果还不能说明什么 |
|---|---|---|
| 双方评估与周期规划 | 明确病因、可选路径和时间安排 | 不能只凭男方一项指标决定完整方案 |
| 卵巢刺激与监测 | 按方案支持卵泡发育并观察反应 | 卵泡数量不等于成熟卵母细胞数 |
| 配子获取与实验室处理 | 获得并核对可供后续使用的卵母细胞与精子 | 获得配子不等于已受精 |
| 常规 IVF 或 ICSI | 在体外完成所选受精过程 | 正常受精不等于获得可移植胚胎 |
| 胚胎培养与评估 | 观察发育并为后续安排提供信息 | 形态评价不能穷尽遗传与发育潜能 |
| 按指征检测、保存或移植 | 将胚胎处理与具体治疗计划衔接 | 移植不等于着床，冻存不等于将来一定能使用成功 |
| 妊娠与结局随访 | 区分检测阳性、临床妊娠、妊娠丢失与活产等结局 | 一次早期阳性结果不能直接记作活产 |

IUI 不经过体外取卵、受精和胚胎培养，不能把这张表完整套在 IUI 上。对某个具体周期，应该先说明采用的技术，再交代哪些环节已经完成、哪些尚未发生。

## 五、成功率与风险怎样解释

先分清受精率、可用胚胎比例、临床妊娠率、活产率和累积活产率；同时说明是每启动周期、每取卵周期、每移植还是每对夫妇，以及随访与年龄分组。

旧稿使用的 2016—2018 年年龄别数据不能代表当前全国水平，也不能作为某位患者的个体预测。本篇不列未经核对的“全国平均成功率”。

风险包括卵巢刺激相关风险、多胎、取卵相关并发症、异位妊娠以及心理负担等。单胚胎移植可减少多胎风险，但具体移植策略需结合适用指南和个体条件。PGT 不能被概括为对所有人提高活产率。

## 六、精子冷冻与生育力保存

在潜在生殖毒性治疗前及其他适当情景讨论保存机会；结合样本质量、可获取方式、保存目的与实验室条件制定计划。冻存前后需要记录样本身份、数量、质量和知情同意。

冻存样本的复苏表现与后续使用方式有关，不能把“已经保存”当作保证未来获得子代。

## 七、男方代谢因素与 ART 结局

后期专题整理了肥胖、糖代谢与受精/妊娠/活产的研究，研究结论与人群、处理方式和结局有关。观察性关联不能直接证明减重等干预能提高活产。

阅读这些资料时保留研究设计、样本量、BMI 定义和置信区间，不把 OR 换写成相同幅度的绝对概率变化。对应专题已进入本知识库，可从分类或全文搜索查阅。
