# 模块八：男科基本手术与术式选择

> 整理日期：2026-11-22。状态：知识框架初稿，待专业复核。当前不宣称已核验最新指南；历史未核实的并发症率、获精率、满意度等数值不再作为默认正文。改动前原稿已保存在 archive/2026-11-22-integration/kb/m8.md。

## 一、学习一台手术的共同框架

围绕适应证、替代方案、术前评估、入路与关键解剖、主要步骤、并发症以及随访结局组织知识。手术目的应具体到改善症状、获取精子、恢复通畅或恢复勃起功能；技术成功与最终临床获益需要分别评价。

本篇是术式与解剖框架，不能替代手术图谱、操作培训、科室 SOP 或个体化术前决策。操作参数、抗菌方案和器械细节应回到对应专业规范。

## 二、精索静脉曲张手术

### 2.1 手术前先确认问题

区分临床可触及的曲张与仅影像发现的改变；结合症状、规范精液检查、睾丸情况、夫妇生育目标及女方因素讨论处理。不能仅凭一条超声管径或“发现曲张”决定手术。青少年评估与成人不育评估的人群和终点不同，应分别查对应指南。

### 2.2 术式与关键解剖

| 方式 | 需要理解的要点 | 不宜忽略的边界 |
|---|---|---|
| 显微腹股沟/腹股沟下途径 | 放大下辨认静脉、动脉、淋巴管和输精管相关结构 | 入路不同，静脉分支与解剖处理不完全相同 |
| 腹腔镜途径 | 从腹腔侧辨认相关精索血管结构 | 需要考虑腹腔操作和对应并发症 |
| 开放途径 | 理解所选结扎层面与可处理分支范围 | 不能与显微术式合并成同一疗效组 |
| 介入栓塞/硬化 | 属血管介入路径，需评估静脉解剖与技术可行性 | 技术失败、残留、复发与再治疗需分开记录 |

### 2.3 基本操作逻辑

术前核对侧别与指征 → 明确所选入路 → 显露相关结构 → 辨认并保护需要保留的血供与淋巴回流结构 → 按术式处理目标静脉 → 检查止血与结构完整性 → 记录手术与随访计划。具体结扎范围和动脉处理不能脱离术式与专业培训概括为一条通用命令。

### 2.4 初次与再次手术

初次手术重点是指征、解剖与术式选择。再次处理时先核对首次入路、术后经过及当前异常，区分残留、复发、疼痛未缓解和其他病因；瘢痕、既往处理结构和残余静脉路径会影响方案。不能只因一次检查异常就套用“再做同一种术式”。

### 2.5 并发症与随访

关注鞘膜积液、出血/血肿、感染、持续疼痛、血供损伤、残留或复发等。评价应分别记录症状、查体/影像、精液变化与妊娠/活产等结局。复发率、再治疗率与失败率不是同一个指标；本篇不引用尚未核定的统一百分比。

## 三、外科取精术

### 3.1 先区分 OA 与 NOA

梗阻性无精子症（OA）主要问题在排出通道；非梗阻性无精子症（NOA）涉及生精功能受损。分类需要综合病史、查体、精液、激素及按指征开展的遗传学等检查，不能仅按 FSH 正常/升高简单二分。

### 3.2 术式名称与取材部位

| 缩写 | 基本含义 | 需要区分 |
|---|---|---|
| PESA | 经皮附睾精子抽吸 | 取自附睾 |
| MESA | 显微附睾精子抽吸 | 显微操作下处理附睾小管 |
| TESA | 睾丸精子抽吸 | 穿刺抽吸，不等于开放切取 |
| TESE | 睾丸组织切取获得精子 | 开放取材 |
| micro-TESE | 显微睾丸精子提取 | 显微寻找候选生精小管并与实验室配合 |

旧模块曾将 TESE 写作睾丸穿刺，容易与 TESA 混淆；本表按术式名称区分。

### 3.3 手术与胚胎实验室衔接

术前明确检查、遗传咨询、样本处理、精子搜索、冻存和 ART 协作计划。手术获取精子与 ICSI 常紧密衔接，但“获精成功”不能直接写作“生育成功”。不同病因与患者选择会改变结局，不能将某中心获精率用于所有 NOA。

### 3.4 初次、重复与补救取精

再次取精前需要核对首次术式、取材范围、病理和实验室记录，以及是否还有冻存精子。需评估重复取材的组织、血供和内分泌风险，并与女方治疗时间协调。遗传缺失的具体类型和完整性会改变判断，不应把所有 Y 微缺失并为一组。

## 四、输精管与附睾重建

输精管-输精管吻合和输精管-附睾吻合处理的梗阻层面不同。应理解管腔对合、组织张力、血供保护以及远近端通畅性等基本原则。既往结扎时间、梗阻原因、术中发现和术者经验会影响选择。

解剖复通、术后精液出现精子和夫妇最终妊娠是不同终点；与取精加 ART 等替代方案的比较需要考虑双方因素。具体缝线、吻合层次与操作步骤应使用对应手术学资料和科室培训规范，不在未核验来源下列通用参数。

## 五、阴茎假体植入

理解可弯曲与可膨胀假体的结构、操作要求和不同使用体验；结合既往治疗、患者目标、感染情况、手部操作能力与解剖条件讨论选择。

基本流程涉及术前评估与知情同意、入路选择、海绵体相关操作、部件置入与检查、止血和术后指导。部件位置和组织条件会受既往盆腔手术等影响，不能套用唯一入路。

初次植入、机械故障翻修、感染处理及分期重建需要分别讨论。发现疑似感染时的移除、补救或分期策略取决于具体情况与专业规范；旧稿“感染一律取出后再二期”的绝对化表述不再沿用。本篇不提供未核实的满意度、寿命或感染率。

## 六、其他基本操作

包皮环切需关注适应证、局部解剖、系带与切除范围、止血、伤口及并发症；术式与设备不同，操作不完全相同。睾丸活检需说明目的，是诊断、与取精同期还是其他特定问题，并评估能否通过其他检查获得答案。精道内镜与射精管处理应先明确梗阻证据和适应证。

睾丸扭转属于需要及时临床评估的急症，不能因等待普通知识问答而延误处理。现有专题可用于理解研究与机制，不代替急诊流程。
