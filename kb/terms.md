# 男科术语表（中英对照 · 文献阅读用）

> 状态：初稿，待导师审核 | 收录男科/不育/性功能障碍常见术语，读英文文献时对照查阅

## 基础解剖与生理

| 中文 | English | 一句话解释 |
|---|---|---|
| 精子发生 | spermatogenesis | 生精小管内从精原细胞到精子的全过程 |
| 支持细胞 | Sertoli cell | 生精小管内支持、营养生精细胞的细胞 |
| 间质细胞 | Leydig cell | 分泌睾酮，位于生精小管之间 |
| 下丘脑-垂体-性腺轴 | HPG axis | GnRH→FSH/LH→性激素的调节轴 |
| 促性腺激素释放激素 | GnRH | 下丘脑分泌，调控垂体 FSH/LH |
| 卵泡刺激素 | FSH | 促进精子发生（作用于 Sertoli 细胞） |
| 黄体生成素 | LH | 促进 Leydig 细胞分泌睾酮 |
| 睾酮 | testosterone | 主要雄激素，维持生精与第二性征 |
| 抑制素 B | inhibin B | Sertoli 细胞分泌，负反馈抑制 FSH |
| 附睾 | epididymis | 精子成熟与储存场所 |
| 输精管 | vas deferens | 输送精子的管道 |
| 精囊 | seminal vesicle | 分泌精浆（含果糖），构成精液 |
| 前列腺 | prostate | 分泌前列腺液，构成精液 |
| 射精 | ejaculation | 分发射（emission）与射出（expulsion）两阶段 |
| 逆行射精 | retrograde ejaculation | 精液逆流入膀胱 |

## 不育与精液分析

| 中文 | English | 一句话解释 |
|---|---|---|
| 无精子症 | azoospermia | 射精中无精子，需区分梗阻性(OA)/非梗阻性(NOA) |
| 少精子症 | oligozoospermia | 精子浓度低于参考值下限 |
| 弱精子症 | asthenozoospermia | 前向运动比例低 |
| 畸形精子症 | teratozoospermia | 正常形态比例低 |
| 少弱畸精子症 | oligoasthenoteratozoospermia (OAT) | 三种异常并存，常见于重度生精障碍 |
| 精液分析 | semen analysis | 精液检查，WHO 标准化的基础检查 |
| 精子浓度 | sperm concentration | 每毫升精液的精子数 |
| 精子总数 | total sperm number | 单次射精精子总量 |
| 前向运动 | progressive motility (PR) | 直线向前运动的精子比例 |
| 精子 DNA 碎片率 | sperm DNA fragmentation (DFI) | 反映精子 DNA 完整性 |
| 抗精子抗体试验 | MAR test | 检测免疫性不育 |
| 禁欲期 | abstinence period | WHO 建议检查前 2~7 天 |
| 精索静脉曲张 | varicocele | 精索蔓状静脉丛迂曲扩张，常见可纠正病因 |
| 隐睾 | cryptorchidism | 睾丸未降入阴囊 |
| 克氏综合征 | Klinefelter syndrome (47,XXY) | 最常见的性染色体异常致无精/少精 |
| Y 染色体微缺失 | Y chromosome microdeletion | 无精/少精的遗传病因之一 |
| 先天性双侧输精管缺如 | CBAVD | 与 CFTR 基因突变相关，梗阻性无精 |
| 囊性纤维化跨膜传导调节因子 | CFTR | 相关基因，CBAVD 需检测 |
| 显微取精 | micro-TESE | 显微镜下寻找局灶生精的取精术 |
| 睾丸精子提取 | TESE | 睾丸组织取精 |

## 性功能障碍

| 中文 | English | 一句话解释 |
|---|---|---|
| 勃起功能障碍 | erectile dysfunction (ED) | 持续不能达到/维持足够硬度勃起 |
| 国际勃起功能问卷-5 | IIEF-5 | 常用的 ED 筛查问卷 |
| 早泄 | premature ejaculation (PE) | 射精缺乏控制、时间过短并致苦恼 |
| 阴道内射精潜伏期 | IELT | 插入到射精的时间，PE 评估参考 |
| 达泊西汀 | dapoxetine | 按需服用的 PE 治疗药物（SSRI 类） |
| PDE5 抑制剂 | PDE5 inhibitor | ED 一线药物（西地那非、他达拉非等） |
| 夜间阴茎勃起监测 | nocturnal penile tumescence (NPT) | 区分心理性与器质性 ED 的检查 |
| 阴茎海绵体多普勒 | penile duplex ultrasound | 评估阴茎血管（ED 病因） |
| 佩罗尼病 | Peyronie's disease | 阴茎白膜纤维斑块致弯曲 |
| 阴茎假体 | penile prosthesis | 难治性 ED 的终末治疗手段 |
| 低促性腺激素性性腺功能减退 | hypogonadotropic hypogonadism (HH) | 垂体/下丘脑病变致睾酮低下 |
| 高泌乳素血症 | hyperprolactinemia | 抑制 GnRH，可致性欲下降/ED |
