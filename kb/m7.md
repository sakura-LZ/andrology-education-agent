## 关键知识点

### 1. 大创与常见选题
- 大学生创新创业训练计划强调学生为主体、早期科研训练
- 男科方向常见选题：某因素与精液质量关联、生活方式/中药干预、人群流行病学调查、量表汉化验证、生物信息学挖掘（公共数据库）、文献计量分析等

### 2. 选题原则
- 小而具体、可操作：避免"太大太空"（"男性不育研究"不可做，"精索静脉曲张术后精液改善的回顾性分析"可入手）
- 有导师资源与数据来源（医院/实验室/问卷）
- 伦理可通过：涉及人均需伦理审批（IRB）+ 知情同意 + 数据脱敏

### 3. 研究设计
1. 明确研究问题（PICO / 科学假说）
2. 选类型：横断面 / 病例对照 / 队列 / RCT（本科生多以前三者或 Meta 分析为主）
3. 样本量估算：依据预期效应量、检验效能（80%）、α=0.05，可用 PASS / G*Power / 在线计算器
4. 变量与测量标准化：精液按 WHO 第 6 版、量表用经信效度验证的中文版、统一纳入排除标准
5. 统计方法：描述统计、t 检验/卡方、相关与回归、OR/RR 与 95%CI；工具 R / SPSS / GraphPad

### 4. 论文与汇报流程、常见坑
- 流程：文献综述 → 开题 → 中期 → 结题
- 报告规范：PRISMA（系统评价）、STROBE（观察性研究）等；结论要克制，不夸大
- 常见坑：样本量太小、无对照、测量不标准、统计滥用（p-hacking）、抄袭与数据造假（红线）

2. 观察性研究写论文时为何要遵循 STROBE 规范？

## 参考答案（初稿，待导师审核）

1. 因为可操作性、数据可得性、伦理可通过是本科生课题能否完成的决定因素；"大而空"的选题无法在有限时间和资源内完成。例如"精索静脉曲张术后 6 个月精液参数改善的回顾性分析"：P=行精索静脉结扎术的男性不育患者，I=手术，C=术前自身对照，O=精液浓度/活力/DFI 变化。
2. STROBE 是观察性研究的报告规范，要求完整报告研究设计、参与者、变量、统计方法等，避免选择性报告和结果夸大，提高可重复性与可信度。
