## 大纲

1. 解剖结构

3. 内分泌调控（HPG 轴）
4. 射精生理

## 关键知识点

### 1. 解剖结构
- **睾丸**：位于阴囊内，生精与内分泌（睾酮）双功能
- **附睾**：精子成熟与储存
- **输精管**：输送精子（梗阻可致梗阻性无精症）
- **精囊、前列腺、尿道球腺**：分泌精浆成分，构成精液
- **阴茎**：三条海绵体（两条阴茎海绵体 + 一条尿道海绵体），勃起依赖海绵体充血

### 2. 精子发生
- 部位：生精小管（曲细精管），由生精细胞 + 支持细胞（Sertoli）构成
- 过程：精原细胞 → 初级精母细胞 → 次级精母细胞 → 精子细胞 → 精子
- 周期约 64~74 天；持续进行，成年后每日产生大量精子
- 间质细胞（Leydig）分泌睾酮，支持精子发生与第二性征

### 3. HPG 轴调控
- 下丘脑 GnRH → 垂体 FSH / LH
- LH → Leydig 细胞 → 睾酮；FSH + 睾酮 → Sertoli 细胞 → 支持精子发生
- 睾酮/抑制素 B 负反馈调节

### 4. 射精生理
- 两个阶段：**发射**（精液排入尿道，交感神经支配）与**射出**（盆底肌节律收缩）
- 射精障碍（早泄/延迟/逆行射精）见模块四及后续内容

## 思考题（待补答案）

1. 简述睾酮在精子发生中的作用。
2. 为什么附睾损伤或梗阻会导致无精或少精？

## 参考答案（初稿，待导师审核）

1. 睾酮由间质细胞（Leydig）分泌，与 FSH 协同作用于支持细胞（Sertoli），为精子发生提供必需的微环境；同时维持第二性征与性欲。睾酮不足时生精障碍（如低促性腺激素性性腺功能减退 HH）。
2. 附睾是精子成熟与储存的场所，输精管是输送管道。附睾损伤或梗阻（如附睾炎后瘢痕、输精管结扎/先天性缺如）→ 精子无法成熟或排出 → 梗阻性无精子症，或精子数量显著下降。
