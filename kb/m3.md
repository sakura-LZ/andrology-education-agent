# 模块三：精液分析与实验室检查

> 状态：初稿，待导师审核 | 参考值以 WHO《人类精液检查与处理实验室手册》第6版（2021）为准，**数值务必请导师核对**

## 学习目标

1. 掌握精液分析的标准操作要点（禁欲时间、采集、送检）
2. 掌握 WHO 第6版参考值下限并能解读报告
3. 熟悉常见异常类型与处理思路（教育层面）

## 大纲

1. 检查规范

## 关键知识点

### 1. 检查规范
- 禁欲 **2~7 天**（WHO 建议）
- 手淫法采集于无菌广口容器，**37°C 保温、1 小时内送检**
- 结果异常时建议复查（一般间隔数周，≥2 次）

### 2. WHO 第6版参考值下限（第5百分位，2021）
| 参数 | 参考值下限 |
|---|---|
| 精液量 | 1.4 mL |
| 精子总数 | 39 × 10⁶ / 次射精 |
| 精子浓度 | 16 × 10⁶ / mL |
| 前向运动（PR） | 30% |
| 总活力（PR + NP） | 42% |
| 存活率 | 54% |
| 正常形态 | 4% |

> 注：与第5版（2010）有微调（如浓度 15→16、前向运动 32%→30%）。教学请以第6版为准，**建议导师审核确认**。

### 3. 结果解读（教育层面）
- **少精子症**：浓度低于参考值下限；按严重程度分轻/中/重
- **弱精子症**：前向运动比例低
- **畸形精子症**：正常形态比例低
- **无精子症**：射精中无精子——需区分**梗阻性**（OA，生精正常）与**非梗阻性**（NOA，生精障碍），进一步查 FSH、遗传学、影像
- 单项异常 ≠ 不育，需结合整体与临床

### 4. 其他相关检查
- 精子 DNA 碎片率（DFI）：反映精子 DNA 完整性
- 精浆生化：果糖（精囊）、中性 α-葡糖苷酶（附睾）——辅助梗阻定位
- 抗精子抗体（MAR 试验）：免疫因素

## 思考题（待补答案）

1. 无精子症的初步鉴别思路：OA vs NOA？
2. 一份报告"浓度 10×10⁶/mL、PR 20%"，如何用参考值解读？

## 参考答案（初稿，待导师审核）

1. OA（梗阻性）生精功能正常：FSH 多正常、睾丸体积正常、精液量少或精浆生化异常（果糖/中性 α-葡糖苷酶），见于输精管缺如/结扎、附睾梗阻；NOA（非梗阻性）生精障碍：FSH 升高、睾丸缩小，需遗传学评估，可尝试 TESE/micro-TESE 取精。
2. 浓度 10×10⁶/mL < 16 → **少精子症**；前向运动 20% < 30% → **弱精子症**；合称**少弱精子症**。单项异常 ≠ 不育，建议复查 ≥2 次并结合整体与临床判断。
