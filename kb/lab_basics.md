# 基础实验操作：原理、流程、对照与排错

> 整理日期：2026-11-22。状态：方法学初稿，待结合实验室 SOP 与试剂说明书复核。
> 本篇是通用操作框架，不是已经在本实验室验证的 SOP。CST WB、细胞免疫荧光与 ATCC 培养指南已读取正文，MIQE 2.0 已核对书目和摘要；细节见相应详解。具体配方、时间、温度、用量以对应细胞、仪器、试剂和抗体说明书及已验证 SOP 为准。

## 一、先明确实验问题与样本

先写清研究对象、处理条件、主要终点和比较组，再决定检测技术。蛋白表达量、RNA 水平、细胞定位和功能变化回答的是不同问题，不宜互相替代。

样本记录应包含来源、物种、组织或细胞系、处理条件、采集与保存过程、冻融记录。处理组与对照组尽量在同批流程中处理；跨批实验应保留共同参考样本。出现污染、样本身份不明或质量不合格时，应先解决样本问题。

生物学重复来自独立生物样本；同一样本的多孔、多次上机通常是技术重复。分析中不能把技术重复直接作为独立的生物学样本扩大 n。

## 二、Western blot：检测目标蛋白

Western blot（蛋白免疫印迹，WB）的常见链条是：样本裂解 → 蛋白定量 → 电泳分离 → 转膜 → 封闭 → 一抗与二抗孵育 → 成像 → 定量与核对。

### 2.1 样本与蛋白提取

裂解体系要适配目标蛋白所在位置以及后续定量和电泳。比较磷酸化状态时，应特别关注取样过程和磷酸酶抑制条件；比较降解敏感蛋白时注意蛋白酶活性与样本处理一致性。记录裂解液组成、蛋白定量方法及上样依据，不以肉眼观察到的条带强弱倒推上样量。

### 2.2 电泳与转膜

凝胶体系、分离范围和转膜条件需要与蛋白大小、性质匹配。先确认上样和电泳是否正常，再用适用的膜上总蛋白染色或其他转膜检查判断是否转移成功。目标条带缺失不等于目标蛋白没有表达，也可能来自提取或转膜失败。

### 2.3 抗体与封闭

记录抗体厂家、货号、批号、识别位点、适用物种和厂家验证用途。封闭剂与稀释条件要服从抗体特性；不要假定牛奶和 BSA 对任何抗体均可互换。二抗必须匹配一抗宿主及所需检测方式。使用多重荧光检测时还要考虑通道串色。

### 2.4 必要的对照

| 对照或检查 | 主要回答的问题 | 常见误区 |
|---|---|---|
| 已知阳性样本 | 检测体系是否能识别目标 | 阳性样本没有信号时直接解释实验组阴性 |
| 敲除/敲低或其他适用阴性样本 | 条带是否具有目标特异性 | 仅凭分子量接近就认定条带身份 |
| 上样/总蛋白控制 | 各泳道上样及归一化是否合理 | 默认 GAPDH、β-actin 永远稳定 |
| 磷酸化与对应总蛋白 | 活化状态变化与总量变化如何区分 | 只比较磷酸化条带而忽略总蛋白变化 |
| 多曝光或线性范围检查 | 信号是否适于定量 | 使用饱和条带进行灰度分析 |

### 2.5 成像与定量

保留完整原始膜图、曝光条件和分子量标记。定量时预先统一目标条带、测量区域、背景扣除方法与归一化方法。确认信号在检测线性范围内；饱和条带与过度背景会破坏相对量比较。不同膜之间直接比较灰度需额外参考与批次控制。

### 2.6 常见问题的排查顺序

| 现象 | 先检查 | 进一步区分 |
|---|---|---|
| 全膜无信号 | 成像/底物体系、抗体匹配、转膜 | 阳性样本与转膜检查是否也失败 |
| 背景很高 | 洗膜、封闭、抗体用量与曝光 | 是均匀背景、局部污点还是非特异条带 |
| 多条带 | 抗体特异性、剪接体、降解 | 阴性样本能否消除相应条带 |
| 条带拖尾或变形 | 样本盐分、降解、上样与电泳 | 是否只影响单个样本或整块胶 |
| 内参随处理变化 | 内参稳定性、样本成分变化 | 改用经验证的归一化策略，不能挑有利内参 |

### 2.7 应保存的原始记录

原始未裁剪图、膜/胶编号、泳道对应表、抗体信息、样本批次、定量原始值、背景与归一化方法、独立重复信息。拼接不同区域时需要清楚标明，不能把不相邻泳道伪装为原始相邻泳道。

## 三、RT-qPCR：检测 RNA 相对表达

实时荧光定量 PCR（qPCR）检测扩增过程；RT-qPCR 在前面增加逆转录步骤。先确定研究问题涉及 RNA 还是基因组 DNA，再选择流程，不能混淆两者。

### 3.1 工作链条

RNA 提取与质量检查 → 评估/去除基因组 DNA 干扰 → 逆转录 → 引物验证 → qPCR → 检查扩增曲线与特异性 → 归一化分析。

RNA 的完整性、抑制物与保存质量都会影响结果；浓度比值本身不等于完整性合格。不同样本的逆转录输入和反应条件应一致，并记录试剂批号、引物序列与扩增区域。

### 3.2 对照与引物验证

| 检查 | 意义 |
|---|---|
| 无模板对照 NTC | 发现试剂污染或引物二聚体等非样本信号 |
| 无逆转录对照 no-RT | 评估基因组 DNA 等非目标来源干扰 |
| 阳性参考样本 | 验证体系具备检测能力 |
| 引物特异性与扩增效率 | 判断扩增是否能代表目标并支持定量 |
| 经验证的参考基因 | 支持稳定归一化；不能默认一个管家基因适用于所有处理 |

染料法可结合熔解曲线检查异常产物，但单一熔解峰不能独立证明产物身份。应根据实验需求结合序列设计、适用的产物检查与阴性对照。

### 3.3 相对定量的边界

常见 ΔΔCq 分析依赖适用的扩增效率假设、明确的校准组以及稳定的参考基因。目标与参考扩增效率不匹配、参考基因受处理影响时，不能机械套用公式。未检出样本的处理规则应预先规定，不可随意给定一个固定 Cq 值以获得期望结果。

### 3.4 排错

技术重复离散时先排查移液、模板混匀和反应质量；晚期非特异信号需结合 NTC、熔解与样本质量判定；RNA 质量不一致时不能只依靠增加技术重复补救。

## 四、免疫荧光：检测位置与分布

通用流程：样本准备 → 适当固定 → 按需通透 → 封闭 → 抗体孵育 → 染核或其他标记 → 成像 → 定量。固定与通透会影响表位保存和细胞结构，不能把一种条件直接用于所有目标。

需要区分真实特异信号、自发荧光、非特异背景和通道串色。阴性对照应针对待解决的问题选择；只省略一抗不能替代敲除样本等特异性验证。

跨组比较图像时保持可比的采集条件，避免饱和；预先规定视野选择、分割阈值与统计单位。共定位图像支持空间接近的观察，不能单独证明两个蛋白直接相互作用。

## 五、细胞培养：身份、状态与污染控制

细胞培养应以所用细胞系的资源库说明及已验证 SOP 为准。明确培养基、补充物、培养环境和传代方式；不同细胞类型不能套用同一传代密度与处理时程。

关键记录包括细胞来源与身份验证、传代号、复苏/冻存批次、培养状态、支原体检测和实验前处理。培养液清亮不能证明无污染；长期使用抗生素也不能替代污染监测。涉及人源样本和生物材料时应遵守所在机构的生物安全要求。

## 六、流式细胞术：从对照到门控

先明确检测的是细胞比例、标志表达还是功能信号。准备合适的单细胞悬液，记录活性、固定/通透过程以及抗体信息。

补偿或光谱拆分需要对应体系的单染等参考对照；FMO 对照主要帮助确定多色条件下的门限，不能替代所有阴性或特异性对照。门控通常需要检查时间稳定性、碎片、单细胞和活细胞，再进入目标群体，具体顺序应匹配样本与目的。

保留原始 FCS、仪器设置、质控记录、门控树与分析版本。跨组比较不能在不说明的情况下分别调门以追求预期阳性率。
